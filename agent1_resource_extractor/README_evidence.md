# AWS Evidence JSON export

Questo modulo genera output JSON riutilizzabili per le evidenze AWS necessarie a risolvere tag incerti.

## Endpoint

POST /extract/evidence

Body esempio:

{
  "job_id": "job-001",
  "account_id": "123456789012",
  "region": "eu-south-1",
  "output_dir": "exports",
  "source_names": ["aws-config", "ec2-eni", "elb", "cloudtrail"],
  "resource_types": ["AWS::EC2::Volume", "AWS::EC2::NetworkInterface", "AWS::EC2::Instance"]
}

## Output

Viene generato un file JSON del tipo:

- exports/aws_evidence_job-001.json

Struttura:

{
  "account_id": "123456789012",
  "region": "eu-south-1",
  "generated_at": "2026-08-31T12:00:00+00:00",
  "sources": ["aws-config", "ec2-eni", "elb"],
  "resource_types": ["AWS::EC2::Volume"],
  "records": [
    {
      "account_id": "123456789012",
      "region": "eu-south-1",
      "resource_type": "AWS::EC2::Volume",
      "source": "aws-config",
      "evidence_type": "provenance",
      "value": null,
      "confidence": 0.0,
      "observed_at": "2026-08-31T12:00:00+00:00",
      "reason": "placeholder generated by local implementation; AWS collection is ready to be populated at runtime"
    }
  ],
  "file_path": "exports/aws_evidence_job-001.json"
}

## Uso da CLI

```bash
# tutte le regioni abilitate (default)
python -m app.evidence --account-id 123456789012 --output-dir exports
# una regione o una lista
python -m app.evidence --account-id 123456789012 --region eu-south-1,eu-west-1 --output-dir exports
```

Le sorgenti regionali (aws-config, ec2-eni, elb, cloudtrail, ssm-inventory, sqs) sono raccolte per ogni
regione (il campo `region` di ogni record indica la regione di origine); quelle globali (cloudfront,
route53, oc-routes, terraform-state) una sola volta, con `region: "global"` in multi-regione.
Il payload contiene `region` (valore richiesto) e `regions` (elenco effettivo). I record includono
l'oggetto AWS completo (`raw` / `attributes` / `configuration`).

## Note

La prima versione è costruita per essere riusabile e serializzabile in JSON; la logica AWS reale può essere aggiunta successivamente a ogni `source` senza rompere il contratto di output.
